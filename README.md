# 🚀 Projeto Prático: Git & GitHub

Este repositório foi criado com o objetivo de praticar os principais comandos do Git e vivenciar um fluxo de trabalho colaborativo real utilizando o GitHub (com divisões de branches, Commits estruturados e resolução de tarefas em equipe).

---

## 👥 Organização da Equipe e Papéis

O projeto foi desenvolvido em trio, onde cada integrante assumiu responsabilidades específicas no fluxo de versionamento:

* **Aluno 01 (Líder do Projeto):** Responsável pela inicialização do repositório, configuração do `.gitignore`, convite dos colaboradores e estruturação inicial deste README.
* **Aluno 02 (Responsável pelas Respostas):** Responsável por criar uma branch própria, responder às questões teóricas deste arquivo e gerenciar os arquivos de imagem locais.
* **Aluno 03 (Responsável pela Pesquisa):** Responsável por pesquisar e documentar padrões de mercado em arquivos separados, utilizando múltiplas branches.

---

## 🛠️ Regras e Requisitos do Projeto

Para que a atividade seja considerada concluída, o projeto segue os seguintes critérios:
- [ ] Repositório remoto configurado no GitHub com o professor (`pedro.lucas.luz.dev@gmail.com`) como colaborador.
- [ ] Uso correto de **Branches** para isolar o trabalho de cada integrante.
- [ ] Histórico de **Commits** organizados e descritivos.
- [ ] Arquivo `.gitignore` configurado corretamente (garantindo que arquivos inúteis e a pasta `img` não subam para o GitHub).
- [ ] Entrega do link do repositório no Google Classroom.
