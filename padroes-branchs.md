# O que são padrões de branches?
Eles são ramificações presente dentro do git para facilitar o desenvolvimento do projeto de forma organizada e direta. As branches são nomeadas, instruindo uma identificação, facilitando o proposito da linha de codigo e melhoram a organização do repositório.

# Tipos de Branchs
feature - Serve para desenvolver novas funcionalidades que serão adicionadas ao projeto no futuro.
hotfix - Usado para resolver erros graves encontrados no ambiente de produção.
bugfix - Serve para corrigir bugs encontrados no código do repositório.
task - Serve para realizar pequenos ajustes e melhorias.
chore - Usado para a manutenção do projeto, atualizando e organizando os codigos.
release - Serve para preparar uma nova versão de software antes de ser lançada.
epic - Serve para gerenciar e organizar projetos que tem outras funcionalidades menores dentro dele.
improvement - Serve para uma melhoria em si, seja de perfomace, layout, escrita e etc.

# Exemplos de nomes de Branchs
feature/add-login-functionality
hotfix/fix-crash-issue
bugfix/fix-login-error
task/update-readme-file
chore/update-dependencies
release/v1.0.0
epic/user-authentication
improvement/improve-login-performance
